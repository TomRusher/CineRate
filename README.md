CineRate

CineRate zobrazuje na stránce Cinema city hodnocení filmů z čsfd a také IMDb 

Jak nainstalovat rozšíření (Pro vývojáře / lokální použití)
1. Stáhněte si tento repozitář jako ZIP (nebo proveďte `git clone`).
2. Rozbalte ZIP archiv do složky ve svém počítači.
3. Otevřete Google Chrome a přejděte na adresu `chrome://extensions/`.
4. V pravém horním rohu zapněte **Režim pro vývojáře** (Developer mode).
5. Klikněte na tlačítko **Načíst rozbalené** (Load unpacked) v levém horním rohu.
6. Vyberte složku s rozbaleným projektem CineRate.
